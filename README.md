# OZO Tip

**Send a Tip. Appreciate Good Work. On-Chain.**

OZO Tip is a decentralized tipping and rewards platform built for the
Ozone Chain ecosystem. It enables users to send crypto tips across
creators, communities, and digital experiences, with transactions
recorded on-chain.

🌐 **Website:** https://ozotip.com/\
⛓️ **Blockchain:** Ozone Chain\
🔗 **Explorer:** https://ozonescan.io/

------------------------------------------------------------------------

## Overview

Creators, contributors, and community members bring value to online
communities every day. OZO Tip provides a simple way to recognize that
contribution through blockchain-based tipping.

Instead of relying only on centralized payment services, OZO Tip uses
smart contracts to record tip transactions on Ozone Chain. This creates
an on-chain transaction history that can be independently inspected
using the network explorer.

OZO Tip is part of the growing Ozone Chain ecosystem.

## Key Features

### On-Chain Tipping

Send crypto tips to recognize creators, contributors, and people whose
work you appreciate.

### Smart Contract-Based Records

Tip transactions are handled through a smart contract. The contract
records tip activity on the blockchain.

### Transparent Transactions

Transactions submitted to Ozone Chain can be inspected through the
blockchain explorer.

### Creator and Community Support

Use tipping to support creators, community members, projects, and
digital experiences.

### Decentralized Infrastructure

OZO Tip is built on Ozone Chain and uses its blockchain infrastructure
for transaction processing and verification.

## How It Works

1.  **Open OZO Tip**\
    Visit https://ozotip.com/.

2.  **Connect or use a supported wallet**\
    Use the wallet connection flow provided by the application.

3.  **Choose the recipient and tip amount**\
    Enter the recipient details and the amount you want to send, using
    the options available in the application.

4.  **Review and confirm**\
    Check the transaction details in your wallet before approving the
    transaction.

5.  **Verify on-chain**\
    Once submitted and confirmed, use the transaction hash to inspect
    the transaction on OzoneScan.

> The exact supported assets, wallet options, minimum tip amounts, and
> application workflow are determined by the live application and
> deployed contract configuration.

## Security Notes

-   Always verify the recipient address before confirming a tip.
-   Review the asset and amount in your wallet before signing.
-   Never share your wallet recovery phrase or private key.
-   Only use the official website: https://ozotip.com/.
-   Confirm transactions using the official Ozone Chain explorer.

Blockchain transactions may be irreversible. Check all transaction
details carefully before confirming.
